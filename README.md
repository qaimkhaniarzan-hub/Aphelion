# WELCOME!
This is Aphelion, a Lunar Lander game which i made myself, completely contained in a single HTML file.
Current features:
-> Procedurally infinitely generating Land
-> A mode for docking (Quite buggy)
-> Missions for credits
-> Upgrades to buy with the credits
<img width="804" height="418" alt="image" src="https://github.com/user-attachments/assets/74d0986f-6bd9-41f6-8f25-664b099a1abc" />

Features I am currently working on:
-> Scroll Zoom
-> More lander models
-> Multiplayer support
-> Levels to docking, each with a higher level of difficulty
-> Procedurally generating sattelites for infinite levels of docking
-> An OST as background music

Features I hope to implement in the future
-> Building your own rocket
-> Launching from Earth
-> Unique scenarios meant to try to survive
-> Avatars (for astronauts)
-> A skin system

Thats pretty much it! Leave comments to give me some ideas

# File Setup:
The files I uploaded in this github repo are basicaly for the dedicated app version, like its in its own window. however, If you just want to run the game or integrate it into ur own web OS , App, or flash it onto a small microcontroller, you can simply download Index.html, bgms.mp3, and lander.png. the rest of the stuff is just to make sure that Your computer doesnt flag it as a virus or anything!
This project is meant to be played on a Pc/laptop/anything with a widescreen display. Although I attempted to add mobile phone support, it didnt quite work, for which I apologize
